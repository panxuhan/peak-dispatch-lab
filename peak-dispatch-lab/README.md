# 高并发 & 实时调度 · 交互实验室

纯前端演示，无需安装依赖、无需构建：**双击 `index.html`** 用浏览器打开即可。

## 两个场景

1. **双十一零点，系统怎么不崩**（`peak.js`）
   - 基线 2 万 QPS，点击「触发零点洪峰」瞬间冲到近 9 万 QPS。
   - 点击画布节点 / 右侧开关开启 CDN、多级缓存、限流、削峰队列、熔断降级等能力。
   - 注入缓存雪崩、热点 Key、机房断电、慢查询等故障，观察 QPS、P99、错误率、DB 负载与排队变化。
   - 「重置演练」回到初始状态。

2. **十万骑手，订单怎么派**（`dispatch.js`）
   - 100,000 名骑手按 1:909 抽样可视化（画布上 180 个光点）。
   - 点击地图下单，点击骑手查看实时状态卡；切换就近 / 负载均衡 / 全局最优 / 随机四种派单策略。
   - 右侧滑块调整骑手规模（1 万–20 万）与订单压力（0.5×–3×）。
   - 注入暴雨（降速 35%）、午高峰（下单 ×2.4）、区域故障、天气转晴。
   - 指标：在线骑手、平均接单、平均送达、准时率、空闲率、派单吞吐。

## 文件结构

```
index.html      页面结构与两个场景的 DOM
styles.css      深色霓虹视觉样式（含响应式）
main.js         公共库：画布自适应、场景注册/切换、日志、音效、工具函数
peak.js         场景一：流量洪峰与稳定性仿真
dispatch.js     场景二：骑手调度仿真与策略算法
boot.js         启动入口（初始化并启动两个场景）
screenshots/    运行效果截图
```

## 运行说明

- 直接以 `file://` 打开即可，所有脚本为普通 `<script>`，无模块跨域限制。
- 音效在首次点击/按键后才会启用（遵循浏览器自动播放策略），右上角可开关。
- 仿真时间：场景一按真实秒推进；场景二为加速仿真（1 秒 ≈ 6 分钟城市时间），便于快速观察送达与准时率变化。
- 建议窗口宽度 ≥ 1200px；窄屏下右侧控制台会下移。
